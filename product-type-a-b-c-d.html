In-Depth FIBC Type Breakdown

TYPE A — Standard Bulk Bags
Non-Hazardous Goods

Type A FIBCs are made from plain woven polypropylene without any electrostatic protection. They are designed exclusively for non-flammable dry goods where no static hazard exists.

Breakdown VoltageNo restriction
Grounding RequirementNot required
Best ApplicationsSand, gravel, stone, grains, non-flammable minerals
Safety RestrictionDo NOT use for combustible powders or gas atmospheres
TYPE B — Anti-Static Breakdown Protection
Breakdown Voltage < 6kV

Type B FIBCs are constructed with thin breakdown coatings to prevent high-energy propagating brush discharges (PBD). Tested to guarantee breakdown voltage stays strictly below 6kV under IEC 61340-4-4 protocols.

Breakdown VoltageStrictly < 6kV
Grounding RequirementNot required
Best ApplicationsDry combustible powders with MIE > 3 mJ (starch, sugar, resins)
Safety RestrictionDo NOT use in presence of flammable solvent vapors
TYPE C — Groundable Conductive Bags
Resistance < 10^8 Ohms

Type C FIBCs feature interconnected conductive carbon grid threads woven throughout the bag body and lifting loops. All conductive components must be grounded during filling and emptying to drain electrostatic charges safely to ground.

Resistance to Ground< 10^8 Ohms
Grounding RequirementMANDATORY operator grounding cable connection
Best ApplicationsExplosive powders, chemical APIs, flammable solvent environments
Safety WarningUn-grounded Type C bags pose severe spark ignition hazard
TYPE D — Crohmiq® Static Dissipative
No Grounding Required

Flexituff is the official licensee of Texene USA producing Type D Crohmiq® static dissipative bulk bags. Engineered with patented quasi-conductive threads that safely dissipate static charges into the atmosphere via low-energy harmless corona discharge without needing any grounding cables.

Dissipation MechanismLow-energy Corona Discharge into air
Grounding RequirementZERO grounding required (Fail-safe operator safety)
LicensingOfficial Texene Crohmiq® USA Licensee
Atmosphere SafetySafe for Zone 1, Zone 2, Zone 21, and Zone 22 hazardous locations
