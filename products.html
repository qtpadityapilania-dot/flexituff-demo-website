FIBCs / Jumbo Bags

Core electrostatic safety types for all industry applications.

IEC 61340-4-4 Certified

Types A, B & C

Electrostatic Safety Classification

The complete IEC-certified classification framework for static electricity control in bulk packaging: Type A (standard), Type B (breakdown <6kV), Type C (groundable conductive), and Type D (Crohmiq® dissipative — no grounding required).

  • Type A: Plain woven, no static protection
  • Type B: Breakdown voltage strictly < 6kV
  • Type C: Conductive grid — mandatory grounding
  • Type D: Crohmiq® — zero grounding needed

Certified by IIP (Indian Institute of Packaging) per IMDG code testing. Subjected to rigorous drop, stacking, topple and tear tests for full international hazardous goods standards compliance.
